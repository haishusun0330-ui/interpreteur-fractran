# Projet : Interpréteur FRACTRAN

## Description

Projet réalisé en Python pour développer un interpréteur du langage FRACTRAN.

Le projet contient trois classes principales :

- `Fraction`
- `Facteur`
- `Fractran`

Le programme permet également de réaliser des additions, des multiplications, de générer la suite de Fibonacci et de rechercher des nombres premiers.

## Fichiers

- `fractran.py` : implémentation des classes FRACTRAN
- `main.py` : programmes et exemples d'utilisation
- `test_fractran.py` : tests unitaires

## Exécution

Pour lancer le programme :

```bash
python main.py```

Pour lancer les tests :

```bash
pytest```
